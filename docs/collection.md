# カードコレクション仕様

## 概要

MARVオリジナルカードは全**30種**。ジェムでパックを開封して収集し、5枚のデッキを組んで「MARV BATTLE」で使用します。

- スターターとして N カード5枚(各属性1枚)を初期配布。そのまま初期デッキになる
- デッキはコレクション画面の「デッキ編成」タブで変更(所持カードをタップで出し入れ)

## カードのパラメータ

| 項目 | 説明 |
|---|---|
| 属性 | 炎🔥 / 森🌿 / 水💧 / 光☀️ / 闇🌙 |
| レアリティ | N / R / SR / UR(高いほどパワーが高い) |
| パワー | バトルの基礎値。N: 20-28、R: 38-44、SR: 58-63、UR: 84-90 |

### 属性相性(バトル時に有利側パワー×1.3)

```
炎 → 森 → 水 → 炎 (三すくみ)
光 ⇔ 闇 (相互有利)
```

相性ボーナス×1.3により、Nカード(28)でも相性次第でRカード(36.4 > 44は無理でも)戦局に絡めるバランス。SRに対してはUR、URに対しては相性の読み合いが必要。

## カード追加の手順(開発者向け)

1. `src/lib/cards.ts` の `CATALOG` に `C(id, 名前, 属性, レアリティ, パワー, 絵文字, フレーバー)` を追加
2. それだけでパック抽選・コレクション画面・バトルに自動反映される
3. パワーの目安は上表のレアリティ帯に合わせる(バランス維持のため)
